# 荷写（NT2 Spreektaal）

一个看中文、默写荷兰语的静态练习网页，面向 NT2 学习者。项目不需要后端，可直接部署到 GitHub Pages。

## 功能

- 支持 A2、B1、B2 各 100 个自建句型
- 句子带难度、话题、来源标签，可搜索和筛选
- 基于拼写相似度即时评分
- 支持键盘默写和手机点击单词排序两种答题方式
- 按掌握度安排 1、2、4、7、14、30 天间隔复习
- 本轮练习、正确率、连续学习天数和七日趋势
- 等级及话题掌握度报告
- 数据仅保存在当前浏览器的 `localStorage` 中
- 报告页可以导出或导入 JSON 进度备份，便于跨设备及本地/线上迁移

## 本地运行

直接打开 `index.html`，或在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 部署到 GitHub Pages

在仓库的 **Settings → Pages** 中，将来源设置为 **Deploy from a branch**，选择 `main` 分支和 `/ (root)` 目录即可。

## 填写你自己的句库

只需要编辑 `my-sentences.js`，分别在 `A2`、`B1`、`B2` 数组中填写 100 条。字段格式和示例已经写在文件顶部。

每条句子包含稳定的 `id`、中文 `zh`、荷兰文 `nl`、话题 `topic` 和来源 `source`。请保持已经发布的 `id` 不变，以免用户已有的学习记录失效。

页面只展示 `my-sentences.js` 中手动加入的句子。句库总数、等级数量和话题筛选都会从这些句子中自动计算；空等级不会显示演示内容。
